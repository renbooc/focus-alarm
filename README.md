# 专注闹钟（Focus Alarm）

`专注闹钟` 是 DeepSeek Harness Web UI 的一块悬浮卡片插件：把番茄钟、下班倒计时和专注统计合成一张可拖动、可收起的小卡片。

## 功能

- **番茄钟**：专注 / 短休 / 长休三段循环，轮次可配（默认 4 轮一次长休），支持开始 / 暂停 / 跳过 / 重置 / `+5` 分钟。
- **每次启动即专注**：DSH 启动时默认回到满时长的「专注」时段；正在运行且未到点的计时会按时间戳续上，不丢进度。
- **完成反馈**：阶段自然结束时响提示音、卡片抖动、彩色粒子迸发、文字气泡提示。尊重系统「减少动态效果」设置。
- **专注统计**：今日完成番茄数、累计专注分钟、打断次数、连续天数、近 7 天柱状图；跨天自动归零并保留历史。
- **下班倒计时**：距下班 / 距上班 / 加班时长、今日工作进度条、周末提示。
- **节律提醒**：距下班 30 分钟收尾、下班点提醒、专注结束护眼提示、加班时段提醒早点收工；同一天只提醒一次。
- **系统通知**：可选 Notification API 推送，权限未授予时静默降级。
- **标签页倒计时**：计时运行时把剩余时间写进浏览器标签页标题，暂停或卸载时精确还原原标题。
- **拖动**：展开时按住标题栏、收起时按住胶囊都能拖动（胶囊本身也是可拖动的把手），位置记忆到下次启动；拖动不会被误判成点击（单击仍展开 / 点按钮），拖出胶囊范围后仍持续跟随。
- **偏好开关**：自动开始下一阶段、提示音、系统通知、标题同步、节律提醒共 7 个开关，即时生效。
- **国际化**：中文 / 英文界面文案自动跟随 Harness 语言设置；配色全部使用主题 token，浅色 / 深色主题自适应。

## 安装

在 Harness Web 里打开 **设置 → 插件 → 插件市场 / 插件广场**，搜索「专注闹钟」一键安装；或命令行：

```sh
dsh plugin --profile web add github:<owner>/focus-alarm#<commit-sha>
```

安装后刷新页面即可，无需重启（客户端插件由 HMR 加载）。

## 开发

```sh
# 本地链接安装
dsh plugin --profile web add /absolute/path/to/focus-alarm
```

目录结构遵循 Cordis bundle 约定：

| 文件 | 作用 |
| --- | --- |
| `package.json` | 包清单，`dsh.bundle.patch` + `dsh.client` 声明 |
| `cordis.patch.yml` | 插入一条插件行 |
| `index.js` | Host 半（空实现，渲染全在 Client） |
| `client.js` | 浏览器半：React 组件、样式、状态、计时逻辑 |
| `locale/*.json` | 中英文显示名与描述 |
| `icon.svg` | 插件图标 |

数据在浏览器 `localStorage` 中，键名前缀 `dsh.offwork-countdown.*`（保留旧前缀以兼容既有安装）。

## 兼容性

- 需要 DeepSeek Harness Web（已验证 `0.2.1-rc.5`）。
- 客户端模块通过 `window.__ModuleLoader__` 注册，注入 `shell.overlay` 槽位；React 由浏览器模块表提供，不重复安装依赖。
